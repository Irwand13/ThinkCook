Riwayat Revisi

Versi 1.1 memperbaiki versi 1.0 sesudah dicek terhadap kode aplikasi: FR-02 dan FR-10 disesuaikan dengan perilaku aplikasi; ditambah FR-15, FR-16, dan NFR-14 untuk autentikasi; NFR-11 dan Bagian 6 diperjelas; Bagian 7 ditulis ulang dan kontras teks dicatat sebagai terverifikasi.

1. Pendahuluan

1.1 Tujuan

Dokumen ini menjelaskan apa saja yang harus bisa dilakukan aplikasi ThinkCook dan seperti apa tampilannya. Dokumen dipakai sebagai pegangan saat membuat dan menguji aplikasi.

1.2 Ruang Lingkup

ThinkCook adalah aplikasi mobile untuk mencari, menyimpan, dan memasak resep. Data resep diambil dari TheMealDB dan aplikasi dibuat dengan Expo (React Native). Versi ini punya login lokal satu perangkat: pengguna mendaftar atau masuk dengan email dan kata sandi; akun dan sesi tersimpan aman di perangkat. Versi ini belum punya unggah resep atau komentar.

2. Gambaran Umum

Produk: aplikasi mandiri yang mengambil data lewat API TheMealDB. Resep favorit disimpan di HP.

Pengguna: orang yang mencari ide masakan, termasuk pemula, dan pengguna yang butuh fitur aksesibilitas seperti pembaca layar atau teks besar.

Platform: Android dan iOS.

Batasan: butuh internet untuk memuat resep, dan nama bahan mengikuti sumber data (bahasa Inggris). Akun hanya berlaku di perangkat tempat dibuat; tidak ada pemulihan kata sandi lewat server.

6. Data dan API

Aplikasi memakai lima endpoint TheMealDB: search.php (cari nama), filter.php (per kategori), lookup.php (detail resep), random.php (pilihan hari ini), dan categories.php (daftar kategori). Data favorit disimpan lokal berisi id, nama, kategori, dan foto resep.

Akun lokal disimpan di SecureStore berisi nama, email, salt, dan hash kata sandi; sesi berisi token acak dan email. Favorit tetap memakai AsyncStorage karena bukan data sensitif.

7. Catatan untuk Perbaikan Desain

  • Bahan dan langkah masih berbahasa Inggris karena berasal dari API TheMealDB, sedangkan antarmuka berbahasa Indonesia.
  • Mode Masak saat ini menandai langkah di halaman yang sama; panduan satu langkah per layar belum diimplementasikan.
  • Layar Masuk belum dirancang di Figma.
  • Kontras teks sudah terverifikasi: semua pasangan teks utama di atas 4,5:1 (mis. primaryDark di putih 4,94:1; secondary di krem 5,91:1).
  • Chip kategori terpilih ditandai ikon centang, bukan hanya warna; status favorit, bahan, dan langkah dibedakan lewat ikon, bukan hanya warna.
Pengecekan terhadap kode (14 November 2026): FR-01 sampai FR-09, FR-11 sampai FR-14 sesuai dengan aplikasi; tombol favorit, tampilan saat memuat, saat hasil kosong, dan saat gagal sudah ada di aplikasi; lima endpoint TheMealDB sesuai dengan kode.
